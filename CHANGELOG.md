# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]
### Added
- Phase 2 "Quality & Maintainability" initiatives: centralized configuration, strict typing, CI pipeline, optimized Docker image, and improved documentation.

### Changed
- Updated runtime services to use the strongly typed configuration object and custom exception hierarchy.

### Fixed
- Ensured watchers and MCP server share validated paths, preventing unsafe filesystem access.
- Updated tests to use centralized `CONFIG.prompts_dir` instead of importing `prompts_dir` directly.
- Standardized exception handling with custom hierarchy across core modules.

## [0.10.0] - 2025-12-03
### Added
- **uv integration** for 10-100x faster dependency installation and reproducible environments.
- `pyproject.toml` with full project metadata, dependencies, and dev tooling configuration.
- `requirements.lock` generated by `uv pip compile` for deterministic builds.
- `Makefile` with common development commands (`make test`, `make lint`, `make quality`, etc.).
- `setup-uv.sh` script for one-command environment setup.
- GitHub Actions workflow updated to use `astral-sh/setup-uv` action with caching.

### Changed
- Dockerfile now uses official uv base image (`ghcr.io/astral-sh/uv`) in multi-stage build.
- Docker build leverages uv's parallel downloads and mount caching for faster builds (<2 min vs ~5 min).
- CI pipeline migrated from pip to uv, reducing install time by ~70%.
- Documentation updated with uv-first installation instructions and development workflow.

### Fixed
- Docker image size reduced by ~15% through optimized layer caching and slimmer runtime dependencies.

## [0.9.0] - 2025-12-03
### Added
- MIT license, initial documentation set, and reorganized pytest suites covering core MCP flows.

### Changed
- Security fixes applied to the initial MCP server implementation before open-sourcing.

### Fixed
- Test suite stabilization ahead of releasing the first public beta.
