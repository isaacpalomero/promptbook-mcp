# 🎨 Generate GitHub Social Preview Image with Python

## 📋 ROL
Eres un experto en generación de imágenes programáticas con Python (PIL/Pillow) y conoces los requisitos de Open Graph para GitHub.

## 🎯 CONTEXTO
Necesitas crear una imagen de social preview (Open Graph) personalizada para un repositorio de GitHub que se verá cuando se comparta el link en redes sociales.

**Requisitos GitHub Open Graph:**
- Dimensiones: **1280x640px** (obligatorio)
- Formato: PNG o JPG
- Tamaño máximo: 1MB
- Se mostrará en: Twitter, LinkedIn, Slack, Discord, etc.

## 🎯 OBJETIVO
Generar una imagen social preview profesional usando Python PIL/Pillow con:
- Diseño GitHub dark theme
- Título del proyecto prominente
- Subtítulo descriptivo
- Stack tecnológico
- Emojis/iconos relevantes

### 2. Script de Generación

```python
from PIL import Image, ImageDraw, ImageFont
import os

# Configuration
CONFIG = {
    'width': 1280,
    'height': 640,
    'bg_color': '#0d1117',  # GitHub dark bg
    'emoji': '📚',
    'title': 'PROMPTBOOK',
    'subtitle': 'Your AI Prompt Cookbook',
    'tech_stack': 'MCP Server + RAG Search',
    'tags': 'Python • ChromaDB • LM Studio • Docker',
    'output': 'social-preview.png'
}

# Create canvas
img = Image.new('RGB', (CONFIG['width'], CONFIG['height']), 
                color=CONFIG['bg_color'])
draw = ImageDraw.Draw(img)

# Gradient background (dark blue to dark gray)
for y in range(CONFIG['height']):
    r = int(13 + (y / CONFIG['height']) * 10)
    g = int(17 + (y / CONFIG['height']) * 15)
    b = int(23 + (y / CONFIG['height']) * 20)
    draw.rectangle([(0, y), (CONFIG['width'], y+1)], fill=(r, g, b))

# Load fonts (macOS Helvetica)
try:
    title_font = ImageFont.truetype('/System/Library/Fonts/Helvetica.ttc', 120)
    subtitle_font = ImageFont.truetype('/System/Library/Fonts/Helvetica.ttc', 50)
    tag_font = ImageFont.truetype('/System/Library/Fonts/Helvetica.ttc', 40)
except:
    # Fallback
    title_font = ImageFont.load_default()
    subtitle_font = ImageFont.load_default()
    tag_font = ImageFont.load_default()

# Draw elements
draw.text((80, 130), CONFIG['emoji'], font=title_font, 
          fill='#ffffff', embedded_color=True)
draw.text((280, 150), CONFIG['title'], font=title_font, fill='#ffffff')
draw.text((100, 300), CONFIG['subtitle'], font=subtitle_font, fill='#8b949e')
draw.text((100, 400), CONFIG['tech_stack'], font=tag_font, fill='#58a6ff')

# Accent line
draw.rectangle([(100, 500), (1180, 505)], fill='#238636')

# Tags
draw.text((100, 540), CONFIG['tags'], font=tag_font, fill='#7d8590')

# Save
img.save(CONFIG['output'], 'PNG', optimize=True)
print(f"✅ Created: {CONFIG['output']} ({CONFIG['width']}x{CONFIG['height']})")
print(f"   Size: {os.path.getsize(CONFIG['output']) / 1024:.1f} KB")
```
